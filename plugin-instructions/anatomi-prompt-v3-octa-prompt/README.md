## Ownership positioning

Anatomi Prompt is a **structural auditor and architect of prompts under the eight Octa-Prompt pillars**. It examines whether a supplied prompt has coherent role/authority, objective/task matrix, context/variables, reasoning/workflow, constraints, edge-case recovery, stop/completion criteria and output schema. It builds or revises prompts to that structural standard.

It does not primarily infer a prompt from external content or reconstruct what an image/video/document might have been generated from. That content-to-prompt work belongs to AI Prompt Finder & Creator.
