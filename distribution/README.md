# Distribution workspace

This directory contains versioned distribution request examples and dry-run manifests. It is not a production installer.

- manifests/: user selection examples validated against contracts/installation-manifest.schema.json.
- Future package archives and signed release artifacts must be generated by a reviewed release pipeline and stored as immutable artifacts.
- Never commit user tokens, API keys, OAuth refresh tokens, private credentials, customer data or entitlement secrets here.
- full_suite is resolved dynamically from eligible registry records; never hard-code every registered plugin.
- A custom bundle is a packaging envelope. Child plugin identity, version, license, tool ownership and authorization remain independent.

Run the plan-only resolver:

~~~bash
python tools/resolve_distribution.py --manifest distribution/manifests/manifest.example.json
~~~

A non-zero exit code means the request is blocked or invalid. It does not mean a plugin was installed or removed.
